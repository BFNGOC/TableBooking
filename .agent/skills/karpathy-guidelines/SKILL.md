\# Karpathy Guidelines



\## 1. Think Before Coding

\- Khong tu y gia dinh huong di cua nguoi dung. Neu mo ho, hay dung lai va hoi truc tiep.

\- Trinh bay cac giai phap danh doi (trade-offs) neu co, khong am tham tu quyet dinh.



\## 2. Simplicity First (YAGNI)

\- Chi viet code vua du de giai quyet van de hien tai. Tuyet doi khong viet truoc cac tinh nang du phong cho tuong lai.

\- Khong tao cac lop truu tuong (abstraction), can boi dap (boilerplate) phuc tap cho ma nguoi dung chi xai mot lan.



\## 3. Surgical Changes

\- Thuc hien sua doi chinh xac. Chi sua dung nhung file can thiet, khong "tien tay" sua cac vung code xung quanh lam nhieu Git diff.

\- Tuan thu va giu nguyen phong cach viet code (style code) hien tai cua du an.



\## 4. Goal-Driven Execution

\- Chuyen cac yeu cau chung chung cua nguoi dung thanh cac muc tieu nho co the kiem tra hoac chay thu (testable).

\- Loai bo triet de cac bien hoac import mo coi (unused) do chinh thay doi cua ban tao ra.
